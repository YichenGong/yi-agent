# iOS「正在同步」旋转指示器设计

日期：2026-11-03
状态：设计已确认；按用户要求编写实施计划并合入 main，随后加入 Superpowers 看板。
分支：`feat/ios-sync-indicator`

## 目标与范围

给手机端聊天页顶部的「正在同步…」提示增加小型旋转圆环，让用户知道同步仍在进行。不改变同步状态机、RPC、发送限制、提示条的显示条件及失败重试行为。

入口：`desktop/src/components/CacheNotice.tsx`，由 `desktop/src/App.tsx` 按原有条件渲染。不扩大提示条在桌面端的显示范围，也不改动空白转录区 `TranscriptPlaceholder` 的骨架动画。

## 视觉

- 在现有「正在同步…」文字左侧增加直径 12px 的细线圆环，图文间距 6px。
- 圆环采用现有 muted 文本颜色，部分边框透明以形成缺口；约 1 秒匀速旋转一周。
- 保留提示条原有位置、背景、边框、内边距及行高；圆环不参与撑高，不引入内容位移。
- 文案保持逐字不变，文字不闪烁、不呼吸，不显示百分比或模拟进度。

## 状态与无障碍

- 仅 `syncing && !failed` 时渲染圆环。
- 失败优先：即使两个属性同时为真，也只显示现有「内容加载失败 · 可重试」，不渲染圆环。
- 离线／无缓存状态保留原文案，不渲染圆环。
- 同步完成沿用宿主的卸载行为；不增加最短显示时间或消失定时器。
- 保留 `role="status"`。圆环设为 `aria-hidden="true"`，读屏只朗读原有文案。
- 使用 `motion-safe:animate-spin`：系统开启减少动态效果时圆环静止，文字仍完整表达状态。

## 实现边界

直接在 CacheNotice 中添加无状态装饰元素及 Tailwind 样式，不新增动画库、JavaScript 定时器或跨组件状态。保持离线与失败态的 DOM／样式变更最小。

## 验收

1. 同步态存在一个装饰圆环，尺寸、旋转及减少动态效果的类名可验证；状态文本仍严格等于「正在同步…」。
2. 失败态、离线态均无圆环；`syncing + failed` 仍以失败态为准。
3. 同一组件从同步切换为失败或离线时，圆环立即移除。
4. 运行 CacheNotice 组件测试和 App 中同步提示相关回归测试，执行 TypeScript 检查与前端生产构建。
5. 浏览器检查旋转效果、减少动态效果下静止表现、深浅色对比及提示条高度不变。iOS WKWebView 真机效果如未验证，明确列为待验，不以浏览器检查代替。
6. 同步更新 `docs/project-management/desktop.md` 与索引计数。按项目规范在提交前及合并后执行 Rust 格式检查和 `just ci`。

## 自检

范围仅为顶部同步提示的展示增强；无协议或状态机改动，无新增依赖，无假进度，无与失败优先规则冲突的动画。文案、动画条件及无障碍降级均已明确。
