# 会话侧栏滚动条与删除按钮重叠修复设计

日期：2026-10-13

## 问题与根因

macOS 桌面端侧栏的会话列表使用整宽 `overflow-y-auto` 滚动容器。macOS 滚动时显示的覆盖式滚动条会占据容器右缘，而会话行的 Pin/Delete 控件紧贴该右缘，导致滚动条覆盖删除按钮的命中区域，按钮可能无法点击。

## 目标

- 滚动条可见时，列表行内的 Delete 按钮仍可正常点击。
- 保留现有滚动行为和滚动条，不更改删除操作语义。
- 不改变顶部控件和搜索栏布局；手机端搜索栏仍与列表一起滚动。

## 方案

在侧栏滚动容器内部，为会话列表内容预留右侧安全间距，使会话行及其操作控件不再延伸到滚动条覆盖区域。安全间距仅作用于列表内容，不缩窄滚动容器本身，也不影响滚动条显示。实现沿用组件现有 Tailwind 布局方式，不引入新依赖或全局滚动条样式。

## 测试

在 `ThreadSidebar.test.tsx` 增加回归断言，验证会话行位于带有右侧安全间距的列表内容区域内，并仍处于原有滚动容器之中；现有删除按钮测试继续验证点击 Delete 会调用对应会话的 `onDelete`。运行侧栏组件测试和桌面端 TypeScript/生产构建。

## 范围外

不隐藏滚动条、不修改删除按钮显隐规则、不调整侧栏宽度、不改造所有应用滚动容器，也不改变手机端抽屉的手势或安全区行为。
